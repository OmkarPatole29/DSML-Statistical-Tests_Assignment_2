# DSML-Statistical-Tests_Assignment_2
# Student Performance Statistical Tests

## Description
This project applies statistical tests to the Student Performance dataset using Python.

## Experiments
- **T-test:** Compares mathematics scores between male and female students.
- **Chi-square test:** Examines the relationship between parental education level and student performance.

## Technologies Used
- Python
- Pandas
- SciPy
- Jupyter Notebook

## Dataset
[Students Performance in Exams – Kaggle](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

## How to Run
1. Install the required libraries using `pip install pandas scipy`.
2. Download the dataset and place the CSV file in the notebook folder.
3. Open the notebook in Jupyter Notebook.
4. Run each cell in order.

## Objective
To understand and apply statistical hypothesis testing using a real-world student performance dataset.
